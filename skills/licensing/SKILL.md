# Licensing

## Rules

- A new dependency whose license conflicts with this
  repo’s LICENSE (e.g. GPL into a permissive app) —
  only if LICENSE is present.
- Copied code without attribution the original license
  requires.
- Removing a NOTICE / copyright header this MR did not
  own.
- “Generated by” blobs that still contain third-party
  GPL.

Pair with `dependencies` for lockfile changes.

## Do not

- Legal advice. Flag a conflict; do not invent a
  license.
